Woodys Lead Program - V14 Desktop-Style Edit Window

This update changes the remote Vercel web portal Lead Detail window so its design more closely matches the desktop app edit window.

Changes included:
- Web Lead Detail window uses a desktop-style fixed 1100 x 820 layout.
- Header is simplified like the desktop popup.
- Tabs use the same basic order and visual style: Edit Info, Schedule Follow-Up, Follow-Up History, Lead Summary.
- Main action buttons are moved to the bottom bar to match the desktop app style.
- Delete, Previous, Next, Close, and Save All Changes are in the same bottom command area.
- Church tools from V13 are preserved.

Commit summary:
Match remote edit window to desktop layout

Install:
Copy these files into the GitHub-connected flooring-leads folder, commit and push in GitHub Desktop or GitHub, wait for Vercel Ready, then refresh flooring-leads.vercel.app with Ctrl+F5.
